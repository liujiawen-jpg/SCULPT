# Anonymous source release

The archive is a code-only snapshot. It excludes Git history/configuration,
author contacts, institutional identifiers, private server paths, job logs,
notebook outputs, experiment predictions, datasets and weights. Project naming
uses SCULPT; the existing `cosit` import/CLI namespace is retained so the J0
implementation and serialized field names stay compatible.

Public dataset providers, public generic prior resources and third-party method
repositories retain their original names, links and licensing notices. These
are external attribution, not this submission's author information. PopPert's
public repository has no selected license: its implementation is **not** copied
or relicensed into this package. The included adapter is separate code.

Numerical seeds are retained exactly, including date-shaped integer seeds.
Changing a random seed to make it look less like a date would change the
experiment. Private job timestamps and filesystem locations are excluded.

## Local checks

```bash
python scripts/check_anonymity.py
python -m pytest -q -p no:cacheprovider tests Compared_methods/tests
```

Run the anonymity checker on the clean distribution tree; generated bytecode,
pytest caches and build metadata should not be included in a submission.
`SOURCE_SHA256SUMS` contains relative-path hashes of included source files.
`RELEASE_CHECKS.json` records the checks performed for this release and their
limits. The standard library checker prints locations/types of possible issues,
not the matched private content.

The current scan also rejects IP addresses and recognizable service-token
patterns. Archive entry timestamps are normalized. The source folder contains
no Git history or server-to-file migration manifest. Public resource providers
and the comparator upstream commits are retained for reproducibility.

The release preserves the registered joint J0 model. Newly added comparison
configurations and their native helpers do not enter SCULPT's predictions,
losses, initialization or validation selector. See [J0 fidelity](J0_FIDELITY.md)
and [implementation limits](REPRODUCIBILITY.md).

This file describes the archive contents. A public hosting account, Git commit
author or repository URL can separately reveal identity. Upload through the
venue's anonymous artifact process and inspect hosting metadata before sharing
its link; this package does not publish to any external service.
